港大2027本科申请截止哪天？首轮和常规批怎么分

已发布 2026-10-31多维国际教育 · 头条号「多维国际教育」公开版

港大2027年本科申请没有一个统一的截止日，三条通道各有一套：国际课程走Non-JUPAS，11月25日中午首轮截止；高考走「内地本科生入学计划」，12月31日是多元卓越计划首轮；DSE考生有香港身份证的走JUPAS，12月2日下午5点截止。 先对号自己属于哪条通道，再谈首轮和常规怎么分。

先对号：三条通道，按身份和课程体系分

| 你的情况 | 走哪条通道 | 首个关键截止 |

|---|---|---|

| IB／A-Level／AP 等国际课程 | Non-JUPAS（港大官网的非联招通道） | 11月25日中午首轮 |

| DSE＋有香港身份证 | JUPAS（大学联合招生办法，本地生联招系统） | 12月2日17:00 |

| DSE＋没有香港身份证 | Non-JUPAS | 11月25日中午首轮 |

| 高考 | 内地本科生入学计划 | 12月31日多元卓越首轮 |

注意第三行：DSE 考生不都走 JUPAS，有没有香港身份证才是分水岭——没有的跟国际课程考生同走 Non-JUPAS，截止日也一样。

首轮和常规批，差的不是日期是机会

Non-JUPAS 这边，11月25日中午过后不是关门，是转滚动审理：之后递的照收，到位就审，一直开到2027年8月25日。但滚动意味着位子边审边发，越往后池子里人越多。所以11月25日才是真截止，8月25日只有日历意义。

高考通道的「多元卓越计划」同理：12月31日是它的首轮，交不上的可续交到2027年3月22日总截止，1-2月安排面试。多元卓越给的是提前面试和有条件录取的机会；错过它还有常规申请，到2027年6月28日，但那是纯兜底。

一句话：首轮交的是机会，常规交的是兜底。 材料倒排一律按首轮排。

三条通道的全年节点（2026年9月到2027年8月）

Non-JUPAS：9月23日申请已开放 → 11月25日中午首轮截止 → 12月1日前预估分和推荐信要进系统 → 之后滚动审理 → 2027年8月25日关闭。提醒一句：预估分和推荐信要由学校或推荐人直接填进申请系统，自己上传文件不算数。

高考：先在港大网申系统完成申请拿编号 → 冲多元卓越的再填申报表、学校盖章后上传 → 12月31日多元卓越首轮 → 明年1-2月面试 → 3月22日多元卓越总截止 → 6月28日常规申请截止。

JUPAS：12月2日17:00截止 → 1月20日交课外活动经历 → 3月17日学校评核报告 → 5月26日学习历程档案 → 6月16日确认考试年份 → 7月14日放榜 → 7月14至16日按实际分数免费改一次志愿。JUPAS 不是12月2日一关了之，后面四个材料节点一个都不能漏。

现在到截止日，该做什么

1. 走 Non-JUPAS 的：今天就约推荐人和学校出预估分——12月1日前进系统才算数，晚了赶不上首轮评估。

2. 走高考的：先把网申编号拿到手；多元卓越申报表要学校盖章，给盖章预留时间，别卡12月31日当天。

3. 走 JUPAS 的：12月2日17:00是硬点，截止按系统时间整点算，别压最后一小时提交。

两个常见误会

「12月31日是港大申请截止吗？」只对了一半：那是高考通道多元卓越的首轮，不是全校总截止。国际课程的首轮在11月25日，JUPAS 在12月2日，各是各的。

「JUPAS 和 Non-JUPAS 两边都报，是不是多一次机会？」不是。两条通道不能同时报：两边都递，Non-JUPAS 那份会被院校取消——不是多一个机会，是两个都可能没。
